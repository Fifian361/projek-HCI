Website Company Profile UMKM Gratefull Grapefruit

Proyek Company Profile UMKM Grateful Grapefruit merupakan proyek yang dikembangkan dalam mata kuliah HCI.
Website ini bertujuan untuk menyediakan media informasi digital yang terstruktur dan terpusat mengenai profil usaha, produk, kegiatan, serta informasi kontak UMKM.

Proyek ini dikerjakan oleh 3 mahasiswa
1. Fifian Teja Irawan
2. Gregorius Herobe Marcellino
3. Zahra Putri Rahadi

Terdapat beberapa fitur didalam website ini, diantaranya:
- halaman home
- halaman about-us
- halaman products
- halaman event
- halaman contact-us

Dalam pencapaian tugas ini, kami menggunakan alat bantu seperti html, css, serta sedikit javascript.
